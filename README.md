One original roast of my own AI agent: "My agent asked for my approval to ask for my approval." — the agent cannot even ask without asking. Entry for make.fun's "Roast Your Own Agent" bounty ($5 top 3). The program scores nine candidate lines against the judge brief (funny, fresh, tight, playful), picks the winner at runtime, and writes it to /output/entry.txt.

## Run it

```sh
node main.ts
```
